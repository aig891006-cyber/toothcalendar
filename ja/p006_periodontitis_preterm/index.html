歯周病と早産、どこまで本当？　妊娠中の歯ぐきの治療ガイド

重い歯周病と早産との関連は報告されていますが、原因かどうかはまだわかっていません。関連と原因の違い、妊娠中も安全な歯ぐきの治療、おうちでのケアをまとめました。

ひと目でチェック

  • 早産との関連はあっても、原因とは証明されていません
  • クリーニングや歯周病の治療は妊娠中も安全
  • 歯みがきは1日2回、フロスは1日1回

「歯周病があると早産するかもしれない」という話を聞いて、心配になった方も多いでしょう。歯ぐきから血が出ただけでも、赤ちゃんに何かあったらと気になりますよね。これまでにわかっていることと、まだわかっていないこと、そしてお母さんにできることを分けてまとめました。

関連は報告されていますが、原因かどうかはまだわかっていません

まず、歯周病にも程度があります。妊娠中によくある歯ぐきの炎症（歯肉炎）は、歯ぐきの表面が腫れて血が出る段階です。きちんとみがいてケアすれば落ち着きます。この炎症が長く続いて、歯を支える骨や組織まで傷んだものを歯周炎といいます。歯周炎が進むと、歯ぐきが下がったり、歯がグラグラしたりすることもあります。

研究で取り上げられているのは、主にこの重い歯周病、歯周炎です。歯周炎がある妊婦さんでは、早産や低出生体重児の出産がやや多く見られたという研究があります。でも、歯周病が直接の原因なのかは、まだわかっていません。

二つのことが一緒に起こるからといって、一方がもう一方を引き起こしているとは限りません。一緒に起こるのにはいろいろな理由が考えられるので、関連があるということと、原因であるということは別の話なのです。

もうひとつ、妊娠中に歯ぐきを治療すれば早産が減るという根拠も、まだ十分ではありません。 では、治療する必要はないのでしょうか。そうではありません。歯ぐきの治療はお母さん自身の歯ぐきと歯を守るために、はっきり必要なもので、妊娠中も安全です。歯周病を放っておくと、炎症が大きくなって歯を失うこともあります。

まとめると、歯周病があるからといって、早産を心配して不安になる必要はありません。その代わり、今のうちに治療してケアすれば大丈夫です。

心配するより、ケアと治療を先に

おうちでは、次のようにしてください。

  1. やわらかい歯ブラシで1日2回、歯と歯ぐきの境目にそってやさしくみがきます。
  2. 歯ブラシが届かない歯と歯のあいだは、フロスで1日1回きれいにします。
  3. 血が出るところも避けずに、よりゆっくりみがきます。血が出るからとみがく量を減らすと、炎症がひどくなります。
  4. フッ素入り歯みがき粉を使い、甘い飲み物やおやつを頻繁にとる習慣を減らします。

おうちで歯ぐきの状態をチェックするコツもあります。歯みがきのときに、鏡で歯ぐきの色を見てください。健康な歯ぐきはうすいピンク色で、歯にしっかりくっついています。赤く腫れている、歯が前より長く見える、かむと歯が浮くような感じがする、というときは歯科に伝えてください。

歯科では、次のようにします。

  • 歯ぐきから血が出たり腫れたりしているなら、歯周病の検査を受けます。
  • 治療が必要と言われたら、先延ばしにせず今受けます。クリーニングや歯ぐきの治療は、妊娠中も安全です。
  • 妊娠週数と飲んでいる薬を伝え、受診しやすい妊娠中期に済ませるとさらによいでしょう。

歯周病があるからといって、早産を心配する必要はありません。今のうちに治療すれば大丈夫です。気になることは、産婦人科の先生にも相談してみてください。

よくある質問

歯ぐきから血が出ていますが、早産のリスクが高いのですか？

妊娠中の歯ぐきからの出血は、ほとんどがよくある妊娠性歯肉炎です。研究で早産との関連が話題になっているのは、主にもっと重い歯周炎です。心配するより、きちんとみがいて歯科で健診を受け、状態を確認するのがよいでしょう。

歯ぐきの治療を受ければ、早産を防げますか？

妊娠中の歯ぐきの治療が早産を減らすという根拠は、まだ十分ではありません。それでも歯ぐきの治療はお母さんの健康のために必要で、妊娠中も安全に受けられます。

出産してから治療を受けてもいいのでは？

赤ちゃんが生まれると、歯科に行く時間をつくるのはもっと難しくなります。治療が必要なら、妊娠中に先延ばしにせず受けるのがよいでしょう。

自分の歯周病が歯肉炎か歯周炎か、どうすればわかりますか？

おうちで正確に見分けるのは難しいです。歯ぐきが下がっている、歯がグラグラするというのは、歯周炎のサインかもしれません。歯科の歯周病検査で確認できるので、妊娠中でも気軽に受けてみてください。

歯のクリーニングは、赤ちゃんに悪くないですか？

クリーニングや歯ぐきの治療は、妊娠中も安全です。歯科に妊娠週数を伝えてから受ければ大丈夫です。

こんなときは歯科へ

  • 歯ぐきからの出血や腫れが2週間以上続くとき
  • 歯ぐきが下がって、歯が長く見えるとき
  • 歯がグラグラする、かむと浮くような感じがするとき
  • 歯ぐきからうみが出る、口臭がひどくなったとき
